# Portfolio

Vite + vanilla JS (no animation libraries)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs /dist, deploy to Vercel / Netlify / any static host
```

All content (name, bio, projects, services, experience, socials) lives in `src/data.js`.
Add real screenshots by dropping images into `/public` and setting `image: '/file.jpg'` on a project.
Colors and fonts are tokens at the top of `src/style.css`.
